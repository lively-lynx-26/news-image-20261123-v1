## How to run

```
python3 main.py
```

Writes `entry.png` (1024×1024, 211,610 bytes) to
`$MAKEFUN_OUTPUT_DIR`, falling back to `<repo>/output`. The program
only copies the image rendered in the build session and verifies its
SHA-256; two runs write byte-identical output. No network is used.

## The image

All text is code-rendered (PIL/DejaVu); the three hero panels are
code-drawn scenes (the Antalya summit hall, Kyiv at night, sea drones
off Benghazi) and the world map is a hand-authored dotted landmask on
a dark-navy ocean. No diffusion images, no copied photographs.
